# Cranny — French terminology sheet (fr)

Register and typography: formal **vous**, as macOS. Buttons and menu items use the **infinitive** ("Ouvrir",
"Afficher", "Ajouter"); instructions to the user use the imperative ("Faites glisser…", "Cliquez sur…"). Sentence
case everywhere (English Title Case menu items become "Vérifier les mises à jour…" style). Guillemets « … » with a
no-break space (U+00A0) inside; no-break space before : ; ! ? ; apostrophe ’; ellipsis … attached ("Réglages…").
Numbers, dates and durations come pre-formatted (French ICU: "4min", "1h 30min", "50 %"). Plural: one (0 and 1),
many (millions; same wording as other), other.

**Cranny** is never translated, never inflected; it takes masculine agreement ("Cranny est ouvert").

## Review rulings (independent review, 2026-10-14)

Confirmed as they stand: Tray = « Étagère »; peek = « mini-aperçu »; HUD = « Indicateur » (as the Russian «Индикатор»);
pipeline = « chaîne »; Join capsule = « Entrer »; Resumed wing word = « Actives » (« Reprises » reads as reruns/repeats
on its own); All day column = « Journée »; « Reste %@ » / « Il reste %@ » / « Depuis %@ » / « Commencée il y a %@ »;
Off = « Désactivé » in every picker (macOS writes « Désactivé » whatever the gender of the other options); key names
Échap / Retour / Espace / Supprimer / Commande; Done = OK / Terminé / Fini; « Ne pas ouvrir en maintenant ⌥ »;
« Saisie directe »; file kinds with their article (only used inside « Nécessite %1$@, mais l’étape précédente produit
%2$@. », checked in PipelineTitles.content). Changed: the Login Items button (see the Login Items row).
